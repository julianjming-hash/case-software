# Contributions

External contributions are initially closed. Repository discussion and issue surfaces are to remain disabled until separately approved. This file does not configure those settings. Julian owns release, disclosure, licensing and deployment decisions.

Keep source material, clinical records, participant data, private operational records and credentials outside the software repository. Only individually vetted test cases and newly authored synthetic fixtures may be admitted. Preserve third-party notices and the names/logos reservation.

Every future change requires the full selected checks, including browser/accessibility, timing gates, real database and Durable Object tests, compatibility and the narrow real Mac shell/database lane. A paid check delayed by an exhausted account budget remains pending; it is never waived. No public launch, push or deploy is authorized by this preparation.
